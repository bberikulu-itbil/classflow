# ClassFlow
Статик сайт: `python3 -m http.server 8000` немесе Netlify/Vercel/GitHub Pages-ке жүктеу.
- Логин: KeyToLife-тағыдай (Supabase жоба tsaqxuutacgbeaaqzivv).
- Мұғалім: сабақ жасау → ▶ Бастау → телефонда пульт, ноутбукта `#board/<id>` (📺 Тақта).
- Оқушы: код немесе тізімнен қосылу.
- DB: cf_* кестелері мен RPC-лар Supabase-те дайын (migrations: classflow_*).

## SQL
`supabase/002_live_code_and_speed.sql` — Supabase SQL Editor-де бір рет іске қос: сабақ таймері (`time`), жылдамдық бонусы (`speed`), Live код кестесі.
