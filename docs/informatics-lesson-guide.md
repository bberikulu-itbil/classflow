# ClassFlow-та информатика сабағын жасау нұсқаулығы (v0.9.1)

Бұл нұсқаулық кодпен жасалатын дәрістерге арналған (`src/lessons/<бума>/`). Ол дәріс ClassFlow-тың бүкіл мүмкіндігін пайдалануы үшін жазылған: сабақта тақтада, оқушының экранында, өз қарқынымен оқуда, ҚМЖ-да және емтиханда.

Әр дәріс **үш нәрсе** болады:

1. **Сабақ** — тақтадағы слайдтар. Қысқа, көрнекі, 45 минутқа арналады.
2. **Электрондық оқулық** — әр түсіндіру слайдының астында толық мәтін мен түсіндірме суреттер тұрады. Оны оқушы өз құрылғысында оқиды.
3. **ҚМЖ** — дәрістің жоспары. Мұғалім оны бір басумен Word файлына шығарады.

---

## 1. Файлдар қайда тұрады

| Не | Қайда |
|---|---|
| Бума (модуль) | `src/lessons/<бума>/a.ts, b.ts …` — бір файлда 1–2 дәріс |
| Ортақ құралдар | `src/lessons/sheetsLab/dsl.ts` (info, walk, quiz, labTask, tag, planData), `src/lessons/info10/lib.ts` (lab, task, vquiz, levels, plan10) |
| Буманың тізімі | `src/lessons/<бума>/index.ts` → `markLesson(...)`, `planData(l, grade)` |
| Суреттер | `scripts/gen-sheetslab-art.mjs` → `public/lec/inf8-<атауы>.svg`, биіктігі `ART_H` (`sheetsLab/cv.ts`) |
| Симуляциялар | `src/components/LabWidgets.tsx` (`widget: { kind … }`) |
| Базаға жүктеу | `scripts/gen-<бума>-sql.mjs` → `supabase/0NN_<бума>.sql` |

Барлық мәтін **үш тілде** жазылады: `T = [kk, ru, en]`.

## 2. Дәрістің қаңқасы (45 минут)

| Кезең (`tag`) | Минут | Слайдтар |
|---|---|---|
| `warmup` | 5 | Тақырып слайды. Өткен сабақты еске түсіретін 1–2 сұрақ (`quiz`). |
| `explain` | 8–10 | 2–4 түсіндіру слайды. **Әрқайсысында оқулық мәтіні мен сурет болады.** |
| `together` / `example` | 8–10 | Шешілген мысал (`walk`) **және** симуляция слайды (`lab`): мұғалім тақтада көрсетеді, оқушы өзі қайталайды. |
| `practice` | 12–15 | `levels` (L1–L3) немесе `labTask`. Тапсырма шартында сурет немесе симуляция болады. |
| `check` | 5–7 | `vquiz`: 3–5 сұрақ, әрқайсысында 2–3 нұсқа. |
| `reflect` | 2 | Қорытынды. Терминдер сөздікке түседі. |

Кезең минуттарының қосындысы **45** болуы керек. Әр слайд `tag(слайд, кезең)` арқылы өз кезеңіне белгіленеді. ҚМЖ-дағы «Ресурстар» бағаны («Слайд 2–5») осы белгілерден өзі толады.

## 3. ҚМЖ: әр дәрісте міндетті

ҚМЖ редакторы (`#kmj/<дәріс>`) өрістерді `cf_lessons.plan`-нан өзі толтырады. Сондықтан әр `LabLesson`-ның `plan` өрісі толық болуы керек:

```ts
plan: {
  prior: T,      // оқушы бұрыннан не біледі
  env: T,        // бағдарлама / құрал (ClassFlow, Python, кесте…)
  source: T,     // оқулық: «Информатика 10, 2-тарау, 2.1»
  codes: ['10.2.1.1', '10.2.1.2'],   // оқу мақсаттарының кодтары, objectives-пен бір ретте
  aim: T,        // «Барлық оқушылар… Көпшілігі… Кейбірі…»
  stages: [
    { k: 'warmup',  min: 5,  do: T /* оқушы */, t: T /* мұғалім */, ev: T /* бағалау */ },
    { k: 'explain', min: 10, do: T, t: T, ev: T },
    …
  ],
  diff: T,       // саралау: L1–L3, көмекші парақ, жұппен
  assess: T,     // бағалау: критерийлер, ҚБ 1–10
  health: T,     // денсаулық және қауіпсіздік: сергіту, компьютермен жұмыс
}
```

- `objectives` — оқу мақсаттарының мәтіні. `codes` болса, ҚМЖ-ға «10.2.1.1 …» болып шығады.
- `index.ts` ішінде `plan: planData(l, <сынып>)` жазылады. Сонда барлық өріс базаға түседі.
- **Тексеру:** дәрісті ашып, ⋯ → ҚМЖ басыңыз. Барлық өріс толып тұруы керек, «Барлығы 45 мин» жазуы қызыл болмауы керек. Сосын **Word** файлын жүктеп, ашып көріңіз.

## 4. Түсіндіру слайды және «Оқулық»

### Слайдтың өзі (тақтаға)
- 3–5 қысқа карточка, әрқайсысы бір ой (≈ 90 таңбаға дейін).
- Мүмкін болса сурет (`art`) қосылады: схема, салыстыру, қадамдар.
- Формула немесе қысқа код `code` өрісіне жазылады.

### Оқулық (слайдтың астында, тек оқушыда)

`info(kind, t, bullets, { read, figs })` — `read` мен `figs` тақтада көрінбейді. Оқушы оларды «📖 Оқулық: толығырақ оқу» бөлімінен ашады (сабақта, өткен слайдтарда, курсты өз бетімен оқығанда).

- **Көлемі:** бір түсіндіру слайдына 150–400 сөз. Бір дәріс ≈ электрондық оқулықтың бір параграфы.
- **Мәтіннің құрылымы:**
  1. `# Неге?` — өмірден мысал, тақырыптың не үшін керегі.
  2. `# Қалай?` — ереже, анықтама, қадамдар.
  3. `# Мысал` — сандармен немесе кодпен толық шешімі.
  4. `# Жиі қате` — 1–2 жиі кездесетін қате және оны қалай болдырмауға болады.
- **Пішімі:**
  - абзацтар бос жолмен бөлінеді;
  - `# ` деп басталған жол — тақырыпша;
  - `- ` деп басталған жолдар — тізім;
  - `**термин**` — қалың, `` `код` `` — код.
- **Суреттер (`figs`):** бір слайдқа 1–3 сурет, әрқайсысының қолтаңбасы болады: `{ art: 'binary-steps', cap: T }`. Мәтінде суретке «1-суретте көрсетілгендей…» деп сілтеме беріледі.
- Тіл қарапайым болсын, оқушыға «сен» деп жазылады. Ұзын сөйлемдерге бөлінбеген абзацтар болмасын. Терминнің орысша және ағылшынша баламасы бірінші рет жақшада беріледі.

## 5. Түсіндірме суреттер

Суреттің түрлері:
- **Схема** — құрылғы немесе процесс бөліктерге бөлініп, бағыттауыштармен көрсетіледі.
- **Қадам-қадам** — 3–5 кадр бір суретте, нөмірленген.
- **Салыстыру** — «дұрыс / қате», «бұрын / кейін».
- **Кесте-үлгі** — ұяшықтар бояумен белгіленген.
- **Жиі қате** — қызыл ✗ белгісімен.

Сурет ережелері:
- SVG форматында, ені 960, ақ фонда. Inter қарпі, жазулары қазақша. Түстер: көк `#2A62E8`, жасыл `#1B6B34`, сарғыш `#C2410C`, күлгін `#5B2DB8`.
- Сурет `scripts/gen-sheetslab-art.mjs` скриптімен (немесе соған ұқсас генератормен) жасалады. Аты `inf8-<атауы>.svg` болады. Атауы мен биіктігі `ART_H`-қа тіркеледі (тіркелмесе, `markLesson` қате береді).
- Бір дәрісте **кемінде 4 түсіндірме сурет** болуы керек (слайдтар мен оқулық бірге есептеледі).
- Мәтінсіз сурет болмайды: әрқайсысының қолтаңбасы болады, ал маңызды мәлімет мәтінде де қайталанады.

## 6. Симуляция мен визуализация

Тақырыпты мысалмен көрсету үшін әр дәрісте **кемінде 1 симуляция** болуы керек. Ол түсіндіру немесе мысал кезеңінде тұрады. Қазір дайын тұрғандары:

| `widget` | Не көрсетеді |
|---|---|
| `{ kind: 'base', mode: 'convert' }` | Санау жүйесіне аудару, әр қадамымен |
| `{ kind: 'base', mode: 'arith' }` | Бағанмен қосу/азайту (қарыз, тасымал) |
| `{ kind: 'circuit', circuit, static?, scene?: 'alarm', hideOut?, hideMid? }` | Логикалық схема: кірістерді ауыстырғанда сымдар жанады, ақиқат кестесі толады |
| `{ kind: 'build', inputs, max }` | Схеманы өзі құрастыру |
| `{ kind: 'adder', bits: 1 \| 2 }` | Жартылай / толық қосындылағыш |
| `{ kind: 'code', mode: 'int' \| 'text' }` | Санның битпен сақталуы (қосымша код), ASCII / Unicode / UTF-8 |
| `demoSheet(...)` | Мұғалім тақтада жұмыс істейтін кесте |
| `sql: {...}` | SQL редакторы, кестесімен |
| `video` + `videoStart` / `videoEnd` | YouTube бейнесінің бір үзіндісі |

**Жаңа симуляцияның сапа талаптары** (оны `LabWidgets.tsx`-ке жаңа `kind` етіп қосасыз):
1. **Бір ой** — бір симуляция бір құбылысты көрсетеді. Мысалы: «сұрыптау алгоритмі салыстыру арқылы жұмыс істейді».
2. **Басқару** — «Қадам», «Ойнату / Тоқтату», «Басынан» батырмалары болады, енгізу өрісі мысалды өзгертуге мүмкіндік береді.
3. **Күйі көрінеді** — әр қадамда не өзгергені түспен белгіленеді, қасында бір сөйлеммен түсіндіріледі.
4. **Тақтада және телефонда** жұмыс істейді: `big` режимінде ірі қаріппен, ал 360 px енде бұзылмайды.
5. **Пернетақтамен** басқарылады: батырмалар нақты `<button>`, `aria-label`-дері бар.
6. Үш тілде жұмыс істейді (`pick(lang, kk, ru, en)`).
7. Сыртқы кітапхана мен желі қолданбайды: бәрі браузерде есептеледі.
8. Бір файлда 300 жолдан аспайды.

Мысал тақырыптар: сұрыптау (көпіршік / таңдау әдісі) бағаналармен, екілік іздеу, цикл және айнымалылар кестесі (trace [кодты қадамдап орындау]), пиксель → RGB → файл көлемі, желіде пакеттің жүруі, стек/кезек, Python кодын қадамдап орындау.

## 7. Тапсырмалар

- **L1–L3 деңгейлер** (`levels`): L1 — үлгі бойынша, L2 — өзгертілген, L3 — өмірлік есеп. Әр деңгейдің жауабы сервер арқылы тексеріледі (`accept`).
- **Кесте тапсырмасы** (`labTask`): критерийлер ұяшық, формула, функция және пішім (`look`) бойынша жазылады.
- **Тест** (`vquiz`): әр сұрақта 2–3 нұсқа болады. Дұрыс жауаптың орны ауысып тұрады (`markLesson` өзі таратады).
- Қайта жіберу ережесі: тест пен қысқа жауапқа бір рет қана жіберуге болады. Қалғанына қайта жіберуге болады, бірақ ең көбі 80% алады. Тапсырма шартында осы ереже ескерілуі керек.

## 8. Емтихан (БЖБ / ТЖБ)

- Курс бетіндегі **«Емтихан / БЖБ қосу»** батырмасымен (құрастырушы) немесе кодпен жасалады: `exam: true`, `qvariants` / `xvariants`.
- Әр тапсырмада 3+ нұсқа болуы керек. Сандық тапсырмалар **шаблонмен** жасалады, сонда әр оқушыға өз жиынтығы түседі.
- Схемалы тапсырма `widget` өрісімен жасалады: `hideOut`, `hideMid`.
