# Дәріс 3. `vector`

## Дәріс паспорты

- **Атауы:** `vector`: өлшемі өзгеретін массив
- **Ұзақтығы:** 90 минут
- **Құру режимі:** қолмен немесе ЖИ арқылы жасалған нобайды өңдеу
- **Алдыңғы білім:** бірөлшемді массив, цикл, индекс
- **Күрделілік:** базалық → олимпиадалық қолдану

## Мақсаты

Оқушы C++ тіліндегі `vector` контейнерінің не үшін қажет екенін түсініп, оның өлшемін өзгерту, элемент қосу, соңғы элементті өшіру және элементтерді цикл арқылы өңдеу тәсілдерін қолданады.

## Күтілетін нәтиже

Дәріс соңында оқушы:

1. `vector` мен кәдімгі массивтің айырмасын түсіндіреді.
2. Бос және алдын ала өлшемі берілген `vector` жасайды.
3. `push_back`, `pop_back`, `size` әдістерін қолданады.
4. `vector` элементтерін индекс және range-based `for` арқылы оқиды.
5. Қарапайым олимпиадалық есепте `vector` қолданады.
6. Индекстің шектен шығуы және бос `vector`-ден өшіру сияқты қателерді таниды.

## Дәріс құрылымы

### 1. Қызығушылықты ояту — 5 минут

**Сұрақ:** Элементтер саны алдын ала белгісіз болса, кәдімгі массивті қолдану қаншалықты ыңғайлы?

Мысал: оқушылардың ұпайлары біртіндеп енгізіледі. Әр оқушыдан кейін массив өлшемін өзгерту қажет болуы мүмкін.

### 2. Қайталау — 5 минут

- массив индексі неше саннан басталады;
- `a[0]` және `a[n - 1]` нені білдіреді;
- цикл арқылы массивті қалай аралаймыз.

### 3. Негізгі түсінік — 15 минут

`vector` — элементтер саны өзгеріп отыратын массивке ұқсас контейнер.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> a;
    a.push_back(10);
    a.push_back(20);
    a.push_back(30);

    cout << a.size() << "\n"; // 3
}
```

Негізгі жазылымдар:

```cpp
vector<int> a;          // бос vector
vector<int> a(n);       // n элемент, бастапқы мәні 0
vector<int> a(n, 7);    // n элемент, әрқайсысы 7

a.push_back(x);         // соңына x қосу
a.pop_back();           // соңғы элементті өшіру
a.size();               // элементтер саны
a[i];                   // i индексіндегі элемент
```

Маңызды ереже: `vector` индексі де `0`-ден басталады.

### 4. Мұғаліммен бірге код жазу — 20 минут

#### Мысал 1. Сандарды оқу және шығару

```cpp
int n;
cin >> n;

vector<int> a(n);
for (int i = 0; i < n; i++) {
    cin >> a[i];
}

for (int x : a) {
    cout << x << ' ';
}
```

#### Мысал 2. Тек оң сандарды жаңа `vector`-ге жинау

```cpp
int n;
cin >> n;

vector<int> positive;
for (int i = 0; i < n; i++) {
    int x;
    cin >> x;
    if (x > 0) {
        positive.push_back(x);
    }
}

cout << positive.size() << "\n";
for (int x : positive) {
    cout << x << ' ';
}
```

#### Мысал 3. Соңғы элементті өшіру

```cpp
if (!a.empty()) {
    a.pop_back();
}
```

`pop_back()` шақырмас бұрын `vector` бос емес екеніне көз жеткізу керек.

### 5. Жеке практика — 25 минут

#### Міндетті тапсырмалар

1. `n` санын және `n` бүтін санды оқып, олардың қосындысын тап.
2. Берілген сандардан тек жұп сандарды жаңа `vector`-ге жина.
3. `vector` ішіндегі нөлдердің санын және нөлден үлкен элементтердің санын шығар.

#### Қосымша олимпиадалық тапсырмалар

4. Бір қатарға енгізілген сандардың ішінен бастапқы реті сақталған қайталанбайтын элементтерді қалдыр.
5. `vector`-дің бірінші және соңғы элементтерін ауыстыр. `n = 0` және `n = 1` жағдайларын ескер.
6. Берілген `vector`-ден теріс сандарды өшіріп, қалған элементтерді сол ретімен қалдыр.

### 6. Жылдам тексеру — 10 минут

1. `vector<int> a(5);` командасынан кейін `a.size()` неге тең?
2. `push_back` қай жерге элемент қосады?
3. Бос `vector` үшін `a[0]` қолдануға бола ма?
4. `a.pop_back()` командасы нені өзгертеді?
5. `for (int x : a)` цикліндегі `x` нені білдіреді?

### 7. Рефлексия — 5 минут

Оқушы үш сөйлемді аяқтайды:

- «Бүгін мен білдім... »
- «Маған түсініксіз болғаны... »
- «`vector` қолдану ыңғайлы, себебі... »

## Дәріс соңындағы бақылау

**Мини-жоба:** оқушылардың ұпайларын оқитын бағдарлама жазу. Бағдарлама:

- ұпайларды `vector` ішінде сақтайды;
- 50-ден жоғары ұпайларды бөлек `vector`-ге жинайды;
- өткен оқушылар санын шығарады.

## Үй жұмысы

1. `vector` ішіндегі ең ұзын үздіксіз оң сандар тізбегінің ұзындығын тап.
2. Бір `vector` ішіндегі нөлдерді соңына жылжыт.
3. Екі `vector`-ді біріктіріп, үшінші `vector` жаса.
4. Қосымша: енгізу көлемі алдын ала белгісіз болған жағдайда `vector` қолданудың себебін 2–3 сөйлеммен түсіндір.

# Дәріс 4. `sort`, `min/max`, `pow`, `abs`, `gcd`

## Дәріс паспорты

- **Атауы:** Дайын функциялар: сұрыптау және сандық амалдар
- **Ұзақтығы:** 90 минут
- **Алдыңғы білім:** `vector`, цикл, функция шақыру
- **Күрделілік:** базалық → олимпиадалық қолдану

Бұл дәрістің мазмұны тығыз. Егер бір сабақ 45 минут болса, оны екі сабаққа бөлу ұсынылады:

- 4А: `sort`, `min/max`, `abs`;
- 4Б: `pow`, `gcd` және аралас есептер.

## Мақсаты

Оқушы дайын кітапханалық функцияны дұрыс таңдап, оның параметрлері мен қайтарылатын мәнін түсініп қолданады. Дайын функцияны қолдану алгоритмді түсінудің орнына жүрмейтінін түсінеді.

## Күтілетін нәтиже

Оқушы:

1. `sort` арқылы өсу және кему ретімен сұрыптайды.
2. `min` және `max` арқылы екі мәнді салыстырады.
3. `abs` арқылы санның модулін табады.
4. `pow` функциясының `double` қайтаратынын біледі.
5. `gcd` арқылы екі санның ең үлкен ортақ бөлгішін табады.
6. Қай функцияға қандай тақырып тиесілі екенін ажыратады.

## 1. Қайталау және кіріспе — 10 минут

Сұрақ: 10 000 санды реттеу керек болса, оларды қолмен салыстырып сұрыптау қанша уақыт алады?

Оқушыға мына ой бекітіледі: стандартты функция дайын алгоритмді қолдануға мүмкіндік береді, бірақ оның жұмыс шартын білу қажет.

## 2. `sort` — 20 минут

```cpp
vector<int> a = {5, 1, 4, 2, 3};

sort(a.begin(), a.end());
// 1 2 3 4 5
```

Кему реті:

```cpp
sort(a.begin(), a.end(), greater<int>());
```

Түсіндіру:

- `begin()` — бірінші элементке сілтеме;
- `end()` — соңғы элементтен кейінгі позиция;
- `sort` аралықты `[begin, end)` түрінде қабылдайды;
- `end()` элементтің өзі емес.

### Бірге орындалатын мысал

```cpp
int n;
cin >> n;

vector<int> a(n);
for (int &x : a) {
    cin >> x;
}

sort(a.begin(), a.end());
cout << a[0] << ' ' << a[n - 1];
```

## 3. `min`, `max`, `abs` — 15 минут

```cpp
int a, b;
cin >> a >> b;

cout << min(a, b) << '\n';
cout << max(a, b) << '\n';
cout << abs(a - b) << '\n';
```

Мағынасы:

- `min(a, b)` — екі мәннің кішісі;
- `max(a, b)` — екі мәннің үлкені;
- `abs(x)` — `x` санының модулі.

Массивтің минимумын табу үшін екі мәнді ғана қабылдайтын `min` функциясын циклмен біріктіреміз:

```cpp
int mn = a[0];
for (int x : a) {
    mn = min(mn, x);
}
```

## 4. `pow` — 10 минут

```cpp
double x, y;
cin >> x >> y;
cout << pow(x, y);
```

`pow(x, y)` — `x` санының `y` дәрежесі. Функция нәтижесі көбіне `double` болады.

Бүтін сандармен жұмыс істегенде дөңгелектеу қатесін ескеру керек. Мысалы, үлкен бүтін дәрежені дәл есептеу қажет болса, арнайы бүтін дәрежеге шығару алгоритмі қауіпсізірек болуы мүмкін.

7-сынып деңгейінде:

- квадрат үшін `x * x` қолдану;
- куб үшін `x * x * x` қолдану;
- бөлшек нәтиже керек болғанда `pow` қолдану ұсынылады.

## 5. `gcd` — 10 минут

```cpp
#include <numeric>

int a, b;
cin >> a >> b;
cout << gcd(a, b);
```

`gcd(a, b)` — екі санның ең үлкен ортақ бөлгіші.

Мысал:

```text
gcd(24, 18) = 6
```

Ескерту: `gcd` C++17 стандартында бар. Егер платформадағы компилятор C++17-ні қолдамаса, бұл функцияға балама ретінде Евклид алгоритмін үйрету керек.

## 6. Аралас практика — 20 минут

### Міндетті тапсырмалар

1. Сандарды өсу ретімен сұрыптап шығар.
2. Берілген екі санның кішісін, үлкенін және айырмасының модулін тап.
3. `a` және `b` сандарының `gcd` мәнін тап.
4. `x` санының квадратын және кубын шығар.

### Олимпиадалық тапсырмалар

5. Сандарды сұрыптап, ең кіші және ең үлкен элементтердің айырмасын тап.
6. Берілген кесінділердің ұзындықтарын оқып, ең үлкені мен ең кішісінің айырмасын тап.
7. Екі санды қысқартылған бөлшек түріне келтіру үшін `gcd` қолдан.
8. `vector` ішіндегі әр көршілес жұптың айырмасының модулін тауып, ең үлкен айырманы шығар.

## 7. Қателерді талдау — 5 минут

Оқушылар келесі қателерді табады:

```cpp
sort(a.begin(), a.end() - 1); // соңғы элемент сұрыпталмай қалады
cout << pow(2, 31);            // нәтиже типін ескермеу керек
cout << a[0];                  // vector бос болуы мүмкін
```

## Бақылау

Кішкентай аралас есеп:

- `n` санды оқы;
- оларды сұрыпта;
- ең кіші және ең үлкен мәнді шығар;
- олардың айырмасының модулін шығар;
- бірінші және соңғы элементтердің `gcd` мәнін шығар.

## Үй жұмысы

1. Үш санның медианасын `min` және `max` арқылы тап.
2. Берілген сандарды кему ретімен сұрыпта.
3. Екі санның ортақ бөлгіштерінің санын `gcd` арқылы тап.
4. Қосымша: Евклид алгоритмімен `gcd` функциясын өзің жаз.

# Дәріс 5. `prefix sum`

## Дәріс паспорты

- **Атауы:** `prefix sum`: аралық қосындыны жылдам есептеу
- **Ұзақтығы:** 90 минут
- **Алдыңғы білім:** `vector`, цикл, индекс, қосынды есептеу
- **Күрделілік:** базалық → олимпиадалық қолдану

## Мақсаты

Оқушы массивтің басынан бастап жиналған қосындыларды алдын ала есептеп, кез келген аралықтың қосындысын бір формуламен табады.

## Неліктен префикстік қосынды керек?

Егер әр сұраныс үшін `[l, r]` аралығын қайтадан циклмен қоссақ, көп сұраныс кезінде бағдарлама баяулайды.

Префикстік қосындымен:

- алдын ала есептеу — `O(n)`;
- әр аралық сұранысы — `O(1)`;
- жалпы күрделілік — `O(n + q)`.

## Күтілетін нәтиже

Оқушы:

1. Префикстік қосындының мағынасын түсіндіреді.
2. `pref` массивін дұрыс құрады.
3. `[l, r]` аралығының қосындысын индекстерден қате жібермей табады.
4. Бірнеше сұранысты тиімді өңдейді.
5. `O(nq)` және `O(n + q)` тәсілдерін салыстырады.

## 1. Қарапайым тәсіл — 10 минут

Массив:

```text
a = [2, 5, 1, 4, 3]
```

Егер `[1, 3]` аралығын қоссақ:

```text
5 + 1 + 4 = 10
```

Бір сұраныс үшін қарапайым цикл жеткілікті. Бірақ 100 000 сұраныс болса, сол элементтер қайта-қайта есептеледі.

## 2. Префикстік массив құру — 20 минут

Ең қауіпсіз жазылым: `pref` өлшемі `n + 1` болады.

```cpp
vector<long long> pref(n + 1, 0);

for (int i = 0; i < n; i++) {
    pref[i + 1] = pref[i] + a[i];
}
```

Мысал:

```text
a    = [2, 5, 1, 4, 3]
pref = [0, 2, 7, 8, 12, 15]
```

Мағынасы:

```text
pref[k] = a[0] + a[1] + ... + a[k - 1]
```

## 3. Аралық қосынды формуласы — 15 минут

0-ден басталатын индекстер үшін `[l, r]` аралығының қосындысы:

```cpp
sum(l, r) = pref[r + 1] - pref[l]
```

Мысал, `[1, 3]`:

```text
pref[4] - pref[1] = 12 - 2 = 10
```

Негізгі код:

```cpp
int l, r;
cin >> l >> r;
cout << pref[r + 1] - pref[l] << '\n';
```

## 4. Бірнеше сұраныс — 15 минут

```cpp
int n;
cin >> n;

vector<long long> a(n);
for (long long &x : a) {
    cin >> x;
}

vector<long long> pref(n + 1, 0);
for (int i = 0; i < n; i++) {
    pref[i + 1] = pref[i] + a[i];
}

int q;
cin >> q;
while (q--) {
    int l, r;
    cin >> l >> r;
    cout << pref[r + 1] - pref[l] << '\n';
}
```

Бұл кодта сұраныс индекстері `0`-ден басталады деп белгіленеді.

## 5. Индекс қателерін болдырмау — 10 минут

Оқушылар мына жағдайларды тексереді:

- `l = 0`;
- `r = n - 1`;
- `l = r`;
- бір ғана элементтен тұратын массив;
- барлық элементтердің қосындысы;
- теріс сандардың болуы.

Негізгі ереже: сұраныс `[l, r]` болса, формуладағы оң жақ индекс `r + 1` болады.

## 6. Практика — 15 минут

### Міндетті тапсырмалар

1. `n` санның префикстік қосындысын құр.
2. `q` сұраныс үшін `[l, r]` аралығының қосындысын шығар.
3. Әр сұраныстағы орташа мәнді тап.

### Олимпиадалық тапсырмалар

4. Бинарлық массивте `[l, r]` аралығындағы бірлер санын тап.
5. Қосындысы `S` болатын ең көп аралықты іздеуге дайындық ретінде барлық аралық қосындыларын түсіндір.
6. Бірнеше күндегі сатылымдардың берілген аралықтағы жалпы санын есепте.
7. Екі префикстік массив арқылы екі массивтің аралық қосындыларын салыстыр.

## 7. Бақылау және рефлексия — 5 минут

Оқушы жауап береді:

1. `pref[i]` нені білдіреді?
2. Неліктен `pref` өлшемі `n + 1`?
3. `[l, r]` қосындысының формуласы қандай?
4. Бір сұранысты қарапайым циклмен және префикстік қосындымен есептеудің айырмасы қандай?

## Үй жұмысы

1. Күнделікті температуралар массиві үшін берілген күндер аралығындағы температура қосындысын тап.
2. Бинарлық массивте әр сұраныстағы бірлер санын тап.
3. Массивте қосындысы ең үлкен болатын `[l, r]` аралығын табуға қандай ақпарат қажет екенін түсіндір.
4. Қосымша: префикстік қосындыны 1-ден басталатын индекспен құрып, екі формуланы салыстыр.
