## 1. Пифагор теоремасы

Тікбұрышты үшбұрышта гипотенуза — 90° бұрышқа қарсы жатқан қабырға. Катеттерді a және b, гипотенузаны c деп белгілесек:

`a² + b² = c²`

Гипотенузаны табу үшін:

`c = √(a² + b²)`

Мұндағы маңызды ой: есепте квадраттар пайда болғандықтан, алдымен a*a + b*b есептеледі, содан кейін ғана түбір алынады.

### C++ үлгісі

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>

using namespace std;

int main() {
    double a, b;
    cin >> a >> b;

    double c = hypot(a, b);
    double area = a * b / 2.0;
    double perimeter = a + b + c;

    cout << fixed << setprecision(6);
    cout << c << '\n';
    cout << area << '\n';
    cout << perimeter << '\n';
}
```

hypot(a, b) математикалық тұрғыдан sqrt(a*a + b*b) өрнегіне тең. Біріншісі дайын стандартты функцияны, екіншісі формуланың кодқа тікелей аударылуын көрсетеді.

## 2. Координаталар арасындағы қашықтық

A(x1, y1) және B(x2, y2) нүктелерін қарастырайық. Осы нүктелерден координата осьтеріне параллель тікбұрышты үшбұрыш құрылады:

`dx = x2 - x1`  
`dy = y2 - y1`

Сонда:

`d = √((x2 − x1)² + (y2 − y1)²)`

### Есепті модельдеу

1. dx және dy айырмаларын табамыз.
2. Айырмалардың квадраттарын қосамыз.
3. Қосындыдан квадрат түбір аламыз.
4. Шарт талап еткен дәлдікпен шығарамыз.

### Дәлдік

Егер жауаптың дәлдігі 10^-5 болса, кемінде 5 цифрды нүктеден кейін шығару керек:

```cpp
cout << fixed << setprecision(6) << answer;
```

fixed нүктеден кейінгі цифр санын бекітеді, ал setprecision(6) алты цифр шығарады.

## 3. Шеңберлер және геометриялық шарт

Екі шеңбердің центрлері арасындағы қашықтықты d, радиустарын r1 және r2 дейік. Олардың кемінде бір ортақ нүктесі болуы үшін:

`|r1 − r2| ≤ d ≤ r1 + r2`

Шекарада жанасуға рұқсат берілсе, қатаң емес салыстыру <= қолданылады.

```cpp
double d = hypot(x2 - x1, y2 - y1);
bool intersects = abs(r1 - r2) <= d && d <= r1 + r2;
cout << (intersects ? "YES" : "NO");
```

Егер барлық мәндер бүтін болса, квадраттарды салыстыру арқылы sqrt қолданбаймыз:

```cpp
long long dx = x2 - x1;
long long dy = y2 - y1;
long long dist2 = dx * dx + dy * dy;
long long sum = r1 + r2;
long long diff = abs(r1 - r2);
bool intersects = diff * diff <= dist2 && dist2 <= sum * sum;
```

Бұл тәсіл нақты сандардағы дөңгелектеу қатесін азайтады. Бірақ көбейту кезінде типтің сыйымдылығын тексеру керек.

## 4. Квадрат теңдеу

Квадрат теңдеу:

`ax² + bx + c = 0`, мұнда `a ≠ 0`.

Дискриминант:

`D = b² − 4ac`

Үш жағдай бар:

- D < 0 — нақты түбір жоқ;
- D = 0 — бір түбір: x = -b / (2a);
- D > 0 — екі түбір:
  - x1 = (-b - sqrt(D)) / (2a);
  - x2 = (-b + sqrt(D)) / (2a).

### Шешу алгоритмі

1. a, b, c мәндерін оқу.
2. D есептеу.
3. D таңбасына қарай тармақталу.
4. sqrt(D) тек D >= 0 болғанда шақыру.
5. Шығыс форматын есеп шартына дәл келтіру.

### Код үлгісі

```cpp
#include <cmath>
#include <iomanip>
#include <iostream>

using namespace std;

int main() {
    double a, b, c;
    cin >> a >> b >> c;

    const double eps = 1e-9;
    double d = b * b - 4.0 * a * c;

    cout << fixed << setprecision(6);

    if (d < -eps) {
        cout << "NO";
    } else if (abs(d) <= eps) {
        double x = -b / (2.0 * a);
        cout << x;
    } else {
        double root = sqrt(d);
        double x1 = (-b - root) / (2.0 * a);
        double x2 = (-b + root) / (2.0 * a);
        if (x1 > x2) swap(x1, x2);
        cout << x1 << ' ' << x2;
    }
}
```

Бұл — түсіндіруге арналған жалпы үлгі. ACMP-тің нақты есебінде түбірлерді шығару форматы басқа болуы мүмкін, сондықтан есеп шарты бірінші орында тұрады. Егер a = 0 жағдайы рұқсат етілсе, теңдеу сызықтық теңдеу ретінде бөлек өңделеді.

## 5. Нақты сандардағы салыстыру

Компьютер нақты сандарды шектеулі дәлдікпен сақтайды. Сондықтан d == 0 орнына:

```cpp
const double eps = 1e-9;
if (abs(d) <= eps) {
    // d нөлге жеткілікті жақын
}
```

тәсілі қолданылады. Бірақ бүтін есепте немесе дискриминант нақты бүтін екені белгілі болса, есептің шартын басшылыққа аламыз.
