# 1-дәріс: Арифметика және алғашқы олимпиадалық есеп

**Курс:** ACMP — C++  
**Модуль:** Введение  
**Тақырып:** Арифметика  
**Ұзақтығы:** 80–90 минут  
**Деңгей:** C++ тілін енді бастаған оқушы  
**Стандарт:** C++17  
**Негізгі есеп:** [A+B](https://acmp.ru/asp/do/index.asp?id_course=1&id_problem=142&id_section=1&id_topic=26&main=task)

> Бұл дәріс ACMP-тегі «Арифметика» тақырыбына арналған. ACMP тақырыптың кіріспесінде бағдарлама құрылымын, `iostream`, `cin`, `cout` және `main` функциясын таныстырады.

## Дәріс соңындағы нәтиже

Оқушы:

- C++ бағдарламасының ең аз құрылымын жазады;
- `cin` арқылы дерек оқып, `cout` арқылы нәтиже шығарады;
- `int` пен `long long` типін сан шектеуіне қарап таңдайды;
- арифметикалық өрнекті жақшамен дұрыс жазады;
- A+B есебін «шарт → алгоритм → код → тексеру» ретімен түсіндіреді.

## 1. Олимпиадалық есепті оқу алгоритмі

Есепті бірден кодқа айналдырмаймыз. Алдымен төрт сұрақ қоямыз:

1. **Не берілген?** — кіріс деректер.
2. **Не табу керек?** — шығыс деректер.
3. **Олардың арасында қандай байланыс бар?** — формула немесе ереже.
4. **Шектеу қандай?** — тип пен алгоритмді таңдауға әсер етеді.

Мысалы, «екі санды қос» деген есепте модель өте қысқа:

```text
a және b беріледі
жауап = a + b
жауапты шығару
```

Бұл да алгоритм. Қарапайым есептерде күрделі цикл немесе массив іздеудің қажеті жоқ.

## 2. C++ бағдарламасының қаңқасы

```cpp
#include <iostream>
using namespace std;

int main() {
    // бағдарламаның негізгі командалары осы жерде жазылады
    return 0;
}
```

### Жолдардың мағынасы

- `#include <iostream>` — енгізу және шығару ағынын қосады;
- `using namespace std;` — `std::cin`, `std::cout` атауларын қысқа жазуға мүмкіндік береді;
- `int main()` — бағдарлама орындалатын негізгі функция;
- `{ ... }` — функция денесі;
- `return 0;` — бағдарлама сәтті аяқталғанын білдіреді.

Оқушы бірінші кезеңде барлық жолды жаттамайды. Маңыздысы — жаңа есепте осы қаңқаны дұрыс қолдану.

## 3. Айнымалы және тип

Айнымалы — мән сақталатын атауы бар орын.

```cpp
int a = 7;
long long big = 10000000000LL;
double x = 2.5;
```

| Тип | Қолданылуы | Мысал |
|---|---|---|
| `int` | кәдімгі бүтін сандар | `42`, `-8` |
| `long long` | үлкен бүтін сандар | `1000000000000LL` |
| `double` | бөлшек мәндер | `3.14` |
| `char` | бір символ | `'A'` |
| `string` | мәтін | `"ACMP"` |

Бастапқы арифметикалық есепте, егер нәтиже бүтін болса, `int` немесе қауіпсіздеу `long long` қолданамыз. Типті таңдаудың негізі — есептегі шектеу, кездейсоқ болжам емес.

## 4. Енгізу және шығару

```cpp
long long a, b;
cin >> a >> b;
cout << a + b;
```

`cin >> a >> b` бір жолдан да, бірнеше жолдан да мәндерді дұрыс оқиды. `cout` бірнеше мәнді де шығара алады:

```cpp
cout << a + b << "\n";
```

`\n` — келесі жолға өту. Артық мәтін шығармаймыз: ACMP тек талап етілген жауапты күтеді.

## 5. Арифметикалық операторлар

| Оператор | Мағынасы | Мысал |
|---|---|---|
| `+` | қосу | `a + b` |
| `-` | азайту | `a - b` |
| `*` | көбейту | `a * b` |
| `/` | бөлу | `a / b` |
| `%` | қалдық | `a % b` |

Екі бүтін санды бөлгенде нәтиже де бүтін болады:

```cpp
cout << 7 / 2; // 3
cout << 7 % 2; // 1
```

Бұл дәрісте `%` тек таныстыру ретінде беріледі; цифрлармен жүйелі жұмыс 1-модульдің «Целые числа» дәрісінде тереңдетіледі.

### Амалдардың реті

Көбейту мен бөлу қосу мен азайтудан бұрын орындалады. Бірақ олимпиадалық кодта ниетті жақшамен көрсеткен дұрыс:

```cpp
long long result = 2 * (a + b);
```

Мына екі өрнек бірдей емес:

```cpp
2 * a + b       // (2 * a) + b
2 * (a + b)     // 2 * a + 2 * b
```

## 6. Негізгі есеп: A+B

### Шартты қысқаша түсіну

Кірісте екі бүтін сан беріледі. Сол екі санның қосындысын шығару керек. ACMP бетінде бұл есеп үшін уақыт пен жад шектеуі де көрсетілген; мұнда алгоритмнің күрделілігі тұрақты: `O(1)`.

### Кіріс және шығыс

```text
Кіріс: a, b
Шығыс: a + b
```

### Қадамдық алгоритм

1. `a` және `b` айнымалыларын жариялау.
2. Екі санды оқу.
3. `a + b` өрнегін есептеу.
4. Нәтижені шығару.

### Псевдокод

```text
оқу a, b
жауап ← a + b
шығару жауап
```

### C++17 шешімі

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b;
    cin >> a >> b;
    cout << a + b << '\n';

    return 0;
}
```

### Қолмен тексеру

Кіріс: `1 2`

| Қадам | Мән |
|---|---:|
| `a` | 1 |
| `b` | 2 |
| `a + b` | 3 |

Шығыс: `3`.

### Шекаралық тексерулер

- екі сан да нөлге жақын болғанда;
- сандардың бірі теріс болғанда, егер шарт рұқсат етсе;
- рұқсат етілген ең үлкен мәндерде;
- сандар бірнеше бос орынмен немесе жаңа жолмен берілгенде.

Шекаралық тесттің мақсаты — кодтың тек үлгіге емес, шарттың барлық рұқсат етілген жағдайына жұмыс істейтінін тексеру.

## 7. Жиі кездесетін қателер

### Қате 1: көбейтуді `x` деп жазу

```cpp
// Қате
long long s = 2 x (a + b);

// Дұрыс
long long s = 2 * (a + b);
```

### Қате 2: айнымалыны оқымай есептеу

```cpp
long long a, b;
cout << a + b; // a мен b-де нақты мән жоқ
```

Алдымен `cin >> a >> b;` орындалуы керек.

### Қате 3: артық мәтін шығару

```cpp
// Қате: ACMP тек сан күтеді
cout << "Answer: " << a + b;
```

### Қате 4: типті тым ерте қысқарту

Егер есепте көбейту немесе үлкен шектеу болса, аралық нәтиже де үлкен болуы мүмкін. `long long` таңдау мәселені автоматты түрде шешпейді, бірақ `int`-тің ерте толып кетуінен сақтайды.

## 8. Мұғаліммен бірге орындалатын мини-тапсырмалар

### Тапсырма A

Үш бүтін санның қосындысын шығарыңыз.

**Оқушының қадамы:** алдымен кіріс пен шығысты сөзбен айтады, содан кейін код жазады.

### Тапсырма B

Тік төртбұрыштың `a` және `b` қабырғалары берілген. Периметрін және ауданын шығарыңыз.

**Формула:**

```text
P = 2 * (a + b)
S = a * b
```

### Тапсырма C

Бір сан берілген. Оның алдындағы және кейінгі бүтін сандарды шығарыңыз.

**Негізгі идея:** бір айнымалыдан екі түрлі өрнек алуға болады: `n - 1` және `n + 1`.

## 9. Exit ticket — 5 минут

1. `cin >> a >> b` командасы не істейді?
2. `cout << a + b` нені шығарады?
3. Неліктен `2 * (a + b)` өрнегінде жақша керек?
4. `7 / 2` бүтін типте неге `3` болады?
5. A+B есебінің алгоритмін үш қадаммен айт.

**Мұғалімге арналған қысқа жауаптар:**

1. Екі мәнді оқиды.
2. Қосындыны шығарады.
3. Қосу алдымен орындалсын деген мағынаны анық көрсетеді.
4. Екі операнд та бүтін болғандықтан, бөлшек бөлігі алынып тасталады.
5. Оқу → қосу → шығару.

## 10. Үй жұмысы

1. ACMP-тегі [A+B](https://acmp.ru/asp/do/index.asp?id_course=1&id_problem=142&id_section=1&id_topic=26&main=task) есебін өз бетіңмен жібер.
2. «Неглухой телефон», «Бисер», «Эния», «Следующее и предыдущее», «Два бандита» есептерінен кемінде үшеуін таңда.
3. Әр есеп үшін дәптерге бір жолмен жаз: **берілгені → формуласы → жауабы**.
4. Бір қате шешімің болса, қате түрін белгіле: формула, тип, енгізу/шығару, синтаксис немесе шекаралық жағдай.

## Дәріс аяқталды деп есептеу шарты

Оқушы:

- A+B есебін дайын кодты көшірмей жазады;
- кодтың әр негізгі жолын түсіндіреді;
- кемінде екі шағын тапсырманы `Accepted` етеді;
- бүтін бөлу мен нақты бөлуді шатастырмайды;
- артық мәтін шығармайтынын біледі.
