# Дәріс: Цикл с постусловием (do ... while)

**Курс:** ACMP — C++  
**Модуль:** Операторы цикла  
**Ұзақтығы:** 90 минут  
**Деңгей:** циклдермен таныс оқушы  
**ACMP беті:** [Цикл с постусловием (do ... while)](https://acmp.ru/asp/do/index.asp?id_course=1&id_section=3&id_topic=35&main=topic)

## Дәрістің мақсаты

Оқушы:

- do ... while синтаксисін қате жібермей жазады;
- while мен do ... while арасындағы негізгі айырманы түсіндіреді;
- денесі кемінде бір рет орындалатын есептерді таниды;
- sentinel мәнімен аяқталатын тізбекті өңдейді;
- циклдегі оқу, өңдеу және тоқтау қадамдарының ретін ажыратады.

## 1. Негізгі идея

do ... while циклі алдымен денені орындайды, содан кейін шартты тексереді:

```cpp
do {
    // кемінде бір рет орындалатын әрекет
} while (condition);
```

while циклінде шарт бірінші тексеріледі:

```cpp
while (condition) {
    // шарт ақиқат болса ғана орындалады
}
```

Егер шарт бастапқыда жалған болса:

- while денені 0 рет орындайды;
- do ... while денені 1 рет орындайды.

Сондықтан do ... while «алдымен бір рет әрекет жаса, кейін жалғастыру керек пе — тексер» деген модельге сәйкес келеді.

## 2. Қарапайым мысал

```cpp
int a = 1;
int b = 10;

do {
    cout << a << ' ' << b << '\n';
    ++a;
    --b;
} while (a < b);
```

Бірінші тексеруге дейін экранға 1 10 шығарылады. Әр айналымда a өсіп, b кемиді. a < b жалған болғанда цикл тоқтайды.

### Trace кестесі

| Айналым | a | b | Шығыс | Кейінгі шарт |
|---:|---:|---:|---|---|
| 1 | 1 | 10 | 1 10 | 2 < 9 — true |
| 2 | 2 | 9 | 2 9 | 3 < 8 — true |
| 3 | 3 | 8 | 3 8 | 4 < 7 — true |
| 4 | 4 | 7 | 4 7 | 5 < 6 — true |
| 5 | 5 | 6 | 5 6 | 6 < 5 — false |

Trace — циклдің шекарасын түсіндірудің тиімді тәсілі.

## 3. Sentinel арқылы тізбек оқу

Кейбір есептерде сандар саны алдын ала берілмейді. Оның орнына арнайы тоқтатқыш мән беріледі, мысалы 0:

```cpp
int x;
long long sum = 0;

do {
    cin >> x;
    if (x != 0) {
        sum += x;
    }
} while (x != 0);

cout << sum;
```

Бұл жерде:

1. бірінші сан міндетті түрде оқылады;
2. ол sentinel болмаса, қосындыға қосылады;
3. 0 келгенде қосындыға қосылмайды;
4. цикл тоқтайды.

Егер тоқтатқыш мән бірінші сан болса, цикл бәрібір бір рет орындалады — бұл do ... while таңдауының себебі.

## 4. Құпия сөз мысалы және online judge ескертуі

Кәдімгі бағдарламада пайдаланушыдан дұрыс пароль келгенше сұрауға болады:

```cpp
string password;
const string correct = "C++";

do {
    cin >> password;
    if (password != correct) {
        cout << "Access denied\n";
    }
} while (password != correct);

cout << "Access granted\n";
```

ACMP есептерінде, әдетте, Input password сияқты сұрау мәтіндерін шығармаймыз. Online judge тек шартта көрсетілген нәтиже мен форматты күтеді. Интерактивті емес есепте код тек кірісті оқып, талап етілген жауапты шығаруы керек.

## 5. while немесе do ... while?

| Сұрақ | while | do ... while |
|---|---|---|
| Шарт қашан тексеріледі? | денеге дейін | денеден кейін |
| Дене 0 рет орындала ала ма? | иә | жоқ |
| Бірінші мәнді алдын ала оқу керек пе? | кейде | цикл ішінде оқылады |
| Ыңғайлы модель | шарт дұрыс болса, орында | орында, содан кейін жалғастыруды шеш |

### Таңдау ережесі

- Кіріс дерегі бірден жарамсыз болуы мүмкін және ештеңе орындамау керек болса — while.
- Бір әрекет міндетті түрде бір рет орындалса — do ... while.
- Sentinel-мен аяқталатын тізбекте бірінші элемент цикл ішінде оқылса — do ... while табиғи көрінеді.

## 6. Жиі кездесетін қателер

### Қате 1: соңындағы нүктелі үтірді ұмыту

```cpp
do {
    cin >> x;
} while (x != 0); // ; міндетті
```

### Қате 2: шартқа әсер ететін мәнді өзгертпеу

Егер x цикл ішінде қайта оқылмаса немесе санауыш өзгермесе, цикл шексіз жүруі мүмкін.

### Қате 3: sentinel-ді жауапқа қосу

Тоқтатқыш 0 қосындыға әсер етпейді, бірақ басқа есепте sentinel -1 немесе басқа мән болуы мүмкін. Шартты есеп мәтінімен салыстыр.

### Қате 4: оқу мен тоқтату ретін шатастыру

```cpp
do {
    sum += x;  // x әлі оқылмаған болуы мүмкін
    cin >> x;
} while (x != 0);
```

Дұрыс тәртіп: оқу → sentinel емес екенін тексеру → өңдеу.

## 8. Мұғаліммен бірге: максимумды табу

Тізбек 0 санымен аяқталсын, ал 0 тізбекке кірмесін.

```cpp
#include <climits>
#include <iostream>
#include <algorithm>

using namespace std;

int main() {
    int x;
    int maximum = INT_MIN;

    do {
        cin >> x;
        if (x != 0) {
            maximum = max(maximum, x);
        }
    } while (x != 0);

    cout << maximum;
}
```

Оқушымен бірге талқылау:

- неліктен maximum = 0 әрқашан дұрыс емес?
- егер бірінші мән 0 болса, maximum қандай күйде қалады?
- есеп шарты бос тізбекке рұқсат бере ме?

Егер бос тізбекке рұқсат етілсе, жауап форматы бөлек өңделеді. Шектеу жоқ жерге өз болжамымызды қоспаймыз.

## 9. Exit ticket

1. do ... while шартты қай кезде тексереді?
2. Дене неше реттен кем емес орындалады?
3. while мен do ... while айырмасын бір мысалмен түсіндір.
4. Sentinel мәні жауапқа қосыла ма?
5. Циклдің аяқталатынын не дәлелдейді?

## Үй жұмысы

- A–E есептерінен кемінде үшеуін шығар;
- F–J ішінен екі есеп таңда;
- бір есепке trace кестесін жаса;
- «Неге бұл жерде while емес, do ... while таңдадым?» деген бір сөйлемдік түсініктеме жаз.
